# Coywolf Data Visualizer

> [!IMPORTANT]
> Coywolf Data Visualizer is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Pack doesn't have a charts module, so there's no direct replacement for this plugin. For the rest of what Coywolf built for WordPress, see [Coywolf Pack's modules](https://github.com/coywolf-llc/coywolf-pack#modules).

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Turned CSV, Excel and JSON files into [Chart.js](https://www.chartjs.org/) charts, with chart suggestions from a built-in analyzer or from Claude, and embedded them in posts and pages with a block.

## If you still use it

The last release, [v1.3.5](https://github.com/coywolf-llc/coywolf-data-visualizer/releases/tag/v1.3.5), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
